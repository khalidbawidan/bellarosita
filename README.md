# جرد المخزون — Double Roses

موقع ثابت (بدون سيرفر) لجرد فساتين الأطفال وطباعة الباركود وتجهيز المنتجات لمتجر سلة.

- البيانات والصور تُحفظ في متصفح الجهاز فقط (localStorage + IndexedDB) — لا تُرفع لأي مكان.
- الكود لكل فستان: `الموديل-اللون-المقاس` مثل `34185-BLU-8Y` (ثابت ولا يتغير).
- الطباعة على Niimbot B1: تصدير Excel للاستيراد في تطبيق NIIMBOT، أو صور PNG جاهزة.

تشغيل محلي: `python -m http.server 8765` داخل هذا المجلد.
